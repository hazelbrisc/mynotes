WEEK 1 - HISTORY

1.Early Writing Systems: 
-Cuneiform - an early writing system using a wedge-shaped tool to write on clay tablets. This earliest form of scripture was developed in Mesopotamia.
-Egyptian Hieroglyphs - a form of writing using symbols to represent objects, numbers and ideas.
-The Epic of Gilgamesh - an ancient literary work written in cuneiform on clay tablets.

2.Number Systems:
-A base-60 number system used by Babylonians.
-Base-60 is still being used today to measure time i.e. 60 seconds in a minute and 60 minutes in an hour.

3.Development of writing:
-Over time writing systems have evolved and some symbols came to represent syllables or sounds.
-Different forms of writing developed around the world including Chinese characters, Japanese Hiragana, Korean Hangul, and Inuktitut syllabics.

4.Printing Technology:
-Woodblock printing was used to carve blocks to print text and images.
-Moveable type was used for individual characters that could be rearranged to print different texts.
-Johannes Gutenberg improved and commercialized the printing press in Europe in the 1450s.

5.Impact of Printing:
-Printing is the reason why producing books and documents were presented more quickly.
-Printing shops helped spread information and ideas to people across cities in Europe.
-Throughout history printing has contributed to major historical changes, including the Protestant Reformation.

6.Typography and Text Formatting:
-Typesetting is the process of arranging letters and text for printing.
-Proportional fonts are used to differ the widths for different characters.
-Monospace fonts gives every character the same horizontal width.
-Carriage return and newline concepts relate by moving to the beginning of a line and starting a new line of text.
 
WEEK 2 - REPRESENTING TEXT AND NUMBERS IN COMPUTERS

1.Binary Number System:
-Binary is  a base-2 number system that only uses two digits : 0 and 1.
-Each binary digit is referred to as a  bit.
-Binary is used to represent and process data by computers.

2.Bits and Bytes
-A bit is the smallest unit of data and it can have the value of 0 or 1.
-A byte consists of 8 bits.
  Numbers, texts, and other information in computers are represented by bits and bytes.

3.Memory and Storage:
-Memory is used by computers to store data and instructions.
-RAM stores data that computer currently uses temporarirly.
-RAM is a volatile memory-when the power is turned off it loses content. 
-Hard drives and SSDs are long-term use to store data.
-Hard drives are non-volitle-when there is no power the data is retained.

4.Endianness:
-Endianness describes the order of bytes accordingly and are stored in computers memory.
-Big Endian will store the most significant byte first.
-Little Endian will store the least significant byte first.
-Endianness affects how the multi-byte values are represented in the memory.

5.Memory as a Series of Bytes:
-A computers memory is organized in the form of long sequence of bytes.
-Every byte has a memory address that will identify its location.
-Computers can access a value stored at a specific memory address.
-Each byte has the ability to store 8 bits of information.

6.Signed Numbers (Positive and Negative):
-Signed numbers represents both positive and negative values.
-Computers uses Two's Compliment to represent signed integers.
-In order to determine whether a number is positive or negative in the Two's Compliment, the leftmost bit helps accomplish this.
-For an 8-bit signed integer the range is ordered from -128 to 127.

7.Fractional Numbers:
-Fractional numbers respresents values that are not whole numbers.
-One example of this is 3.14159,0.000000001, and 99.99.
-Computers need a way to represent numbers with decimal parts.
-Floating-point notation is a common use to represent very large, very small and fractional numbers.

8.Fixed-Point Notation:
-Fixed-point notation is used to represent numbers by keeping the decimal point in a fixed poaition.
-It can be used as a way to store prices as whole number of cents.
-For example, $3.45 can turn into and be stored as 345 cents.
-Fixed-point notation is useful for having when a consistent number of decimal places is required.

9.Floating-Point Notation:
-Floating-point notations represents the numbers using a significand and an exponent.
-It will represent very large, very small and fractional values.
-Computers commonly use the IEEE 754 standard for floating-point numbers.
-Floating-point values can have rounding errors due to some numbers not being able to be represented exactly in binary.

10.Representing Texts with bits:
-Computers will store text as binary data that are made up of bits.
-Character encodings will assign the numeric value to letters, digits and symbols. 
-ASCII is an encoding system used to represent characters using numeric codes.
-Unicode supports characters and writing in systems in many languages.

9.Structured Data in Text Format: JSON and XML:

-Wildcards represent unknown characters within file names or simple searches.
-* commomly represents zero or more characters.

16.Regular Expression (RegEx)
-Regular Expressions are patterns used to search, match replace, and process text.
-They are more powerful than the basic wildcards.

17.Widcards vs. Regular Expressions:
-Wildcards are commonly used for basic file searches.
-Regular expressions supports more detailed pattern matching.
-Example wildcard: *.txt.
-Example RegEx: \d{3}-\d{2}-\{4}, which matches three digits, a dash, two digits, another dash, and four digits.

18.History of Wildcards and Regular Expressions:
-Wildcards become common in early operating systems to simplify file and directory searches.
-The asterisk wildcard was popularized in Unix command-line operations during the 1970S.
-Regular expressions developed from mathematical work on patterns and sets.
-Stephen C. Kleene contributed foundational mathematical concepts in the 1950s.
-Ken Thompson helped popularize regular expressions through Unix tools such as grep in the eralyy '70s.


WEEK 5 - COMMAND LINE INTERFACES (CLI)

1.CLI:
-Allows users to interact with a computer by typing in commands.
-It is an important way to manage files, run programs and perform system tasks.

2.Batch Mode:
-In Batch Mode the programmer prepares the program and input data using punch cards or tape.
-it was ran by a computer operator.
-The returned results were paper printouts.
-The computer performed work without the user required to interact with it continuously.

3.Interactive Terminals-The Original Command Line
-Early interactive terminals allowed users to enter commands directly.
-The user types a command then press enter.
-The computer printed its response on paper.
-Teletype machines were examples of these early terminals.

4.Video Terminals:
-Paper printouts were replaced by computer monitors with Video Terminals.
-Users continued to type commands and press Enter.
-The computer displayed the results on a screen.
-The VT100 terminals was released in '78.
-The VT05 was an earlier mode introduced in '70.

5.Different Types of CLI environments:
-Linux/macOS is a common use in Unix-style shells.
-Windows Command Prompt uses traditional Windows commands.
-PowerShell supports the Windows administrator and scripting.
-Git Bash provides a Bash-style command-line environment on Windows.
-WSL permits the Linux environment to run alongside Windows 

6.Using CLI Today:
-Reasons to use command-line iterfaces are no GUI, precise control, automation, speed, remote access, and low resource usage.
-Some tasks are difficult to perform through CLI- can't do everything through it.
-There are CLI browsers, but their capabilities are limited in comparison with graphical browsers.
